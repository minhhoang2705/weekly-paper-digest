Open-source voice creation for macOS and Windows. Local TTS, voice cloning, and emotion control — no cloud APIs or per-character fees. README: yovoice Give your words a voice. English · 简体中文 CLI & Agent Skill · API / MCP Deployment · Development --- yovoice is an open-source voice creation tool for macOS and Windows that turns text into natural, expressive speech locally. With voice cloning, emotion control, audio project management, and a choice of TTS models, it requires no cloud API calls and incurs no per-character charges, giving you more control over narration, voiceovers, and audio content creation at a lower cost. --- Features. - Voice and expression — use a reference voice, match a reference performance, adjust emotions, or describe the delivery in words. - A complete audio workflow — import or record reference audio, trim clips, preview speech, and export your work. - Voice design and cloning — VoxCPM2 offers text-guided voice design, controllable cloning, and transcript-assisted cloning with automatic multilingual handling, and 48 kHz output. - Music generation — describe a style, write lyrics with section markers, and generate full songs or instrumentals with ACE-Step 1.5; every take is kept as a version to compare. - Score — write each part by bar and beat, import MIDI or let an Agent write the score, then render it with a General MIDI sound font and a role-based mix; results are exactly repeatable and export to MIDI and stems. See Score. - Optional AI service — connect DeepSeek, Qwen, Kimi, OpenAI, Anthropic, Ollama or any compatible API to let AI write arrangements and lyrics; keys stay on this computer. See AI service. - Local models — run IndexTTS 2.0 / 2.5, VoxCPM2, OmniVoice, Qwen3-TTS and Kokoro through audio.cpp, with resumable model downloads and GGUF import. - Hardware acceleration — Metal on Apple Silicon; CPU, NVIDIA CUDA, and experimental Vulkan on Windows. - Agent Skill — ask your AI agent to set up local speech generation and create voiceovers from text and reference audio. --- Supported Models. | Model | Parameters | Model file size by precision | Core capabilities | | IndexTTS

Key idea

yovoice là một ứng dụng desktop mã nguồn mở (phiên bản 0.2.0) chạy cục bộ trên macOS và Windows, tích hợp nhiều mô hình TTS, voice cloning và tạo nhạc. Dự án cung cấp giao diện làm việc hoàn chỉnh, hỗ trợ CLI, Agent Skill và API/MCP server mà không cần phụ thuộc vào cloud API trả phí.

Problem

Việc lồng tiếng, tạo giọng đọc (narration/voiceover) và sản xuất nội dung âm thanh thường phụ thuộc vào các dịch vụ cloud API đắt đỏ tính phí theo ký tự, thiếu quyền riêng tư và hạn chế khả năng kiểm soát chi tiết cảm xúc hoặc kiểu trình diễn.

Methodology

yovoice tích hợp engine suy luận cục bộ audio.cpp (hỗ trợ tăng tốc phần cứng qua Metal trên Apple Silicon, cùng CPU, NVIDIA CUDA 12.4/13.3 và Vulkan thử nghiệm trên Windows). Hệ thống cho phép tải và import các mô hình GGUF ở nhiều mức lượng tử hóa (Q8, BF16, F16, ORIG). Các mô hình và tính năng cốt lõi bao gồm: VoxCPM2 (2B, xuất âm thanh 48 kHz, voice design bằng văn bản, voice cloning hỗ trợ transcript); IndexTTS 2.0/2.5 (cloning, điều khiển cảm xúc, chỉnh sửa phát âm); OmniVoice (0.6B, voice design dựa trên thuộc tính, thẻ âm thanh phi ngôn ngữ); Qwen3-TTS (0.6B/1.7B với clone, custom voice, voice design không cần audio mẫu); Kokoro-82M (giọng tích hợp gọn nhẹ); ACE-Step 1.5 Turbo (sinh bài hát/nhạc cụ từ style prompt và lời); và module Score dựng nhạc MIDI lặp lại chính xác bằng bộ tổng hợp SoundFont (go-meltysynth).

Setup

Hỗ trợ hệ điều hành macOS 14+ (Apple Silicon qua file .dmg) và Windows 10/11 x64 (bộ cài exe đi kèm runtime CUDA 12.4 hoặc CUDA 13.3, yêu cầu WebView2 Runtime). Cung cấp lệnh yovoice serve triển khai authenticated HTTP API / MCP service và Agent Skill cho AI agent. Dữ liệu người dùng lưu tại ~/.yovoice.

Results

  • Không có kết quả định lượng cụ thể (như MOS, WER, RTF hay latency đo lường) được công bố trong tài liệu.

Limitations

Tài liệu không cung cấp các phép đo benchmark định lượng cụ thể về tốc độ suy luận hoặc chất lượng âm thanh; trọng số mô hình OmniVoice mang giấy phép CC-BY-NC giới hạn mục đích phi thương mại; một số tính năng như Vulkan trên Windows và Kokoro-82M 1.1-zh vẫn ở trạng thái thử nghiệm.

Takeaways

Cung cấp một giải pháp đóng gói all-in-one rất tiện dụng cho kỹ sư âm thanh và nhà phát triển cần triển khai hệ thống TTS/voice cloning cục bộ thông qua desktop UI, CLI tự động hóa hoặc MCP server mà không tốn chi phí API.
