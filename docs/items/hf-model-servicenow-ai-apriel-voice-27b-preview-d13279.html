Apriel Voice 27B Preview. An open model for speech, reasoning, and tool use from ServiceNow Apriel Voice 27B Preview understands spoken requests, reasons over conversational context, and generates text responses and tool calls through a shared Gemma 4 backbone. It adds a speech interface while retaining text and image input capabilities. Pair it with an external speech synthesizer to build interactive voice assistants, customer support workflows, and spoken tool use. Try Apriel Live · Read the blog · Technical report Model capabilities. | Capability | What it supports | | Speech understanding | Transcription, translation, and spoken question answering. | | Reasoning and tool use | Following instructions, handling multi-step requests, and generating structured tool calls. | | Multimodal context | Audio, text, images, and tool results in a shared conversation. | | Voice applications | Text responses paired with external speech synthesis and application-managed turn-taking. | The model supports transcription, speech translation, spoken instruction following, reasoning, and function calling. The application executes tools and returns their results to the conversation. Real-time voice interaction is supported by the application and serving stack; the checkpoint itself generates text and tool calls rather than native full-duplex speech. A Whisper large-v3-turbo speech encoder connects to the Gemma 4 26B-A4B backbone through a learned projector. Training first aligns this speech interface, then adapts it with the backbone using speech tasks and text replay. Cross-entropy and teacher-distillation supervision vary by data source; the technical report describes the full recipe. Long audio. The processor automatically splits longer 16 kHz mono recordings into 30-second chunks. In testing, we observed good performance on continuous recordings up to around 30 minutes. Key idea

Apriel Voice 27B Preview là mô hình ngôn ngữ - giọng nói mã nguồn mở (MIT) từ ServiceNow-AI, kết hợp bộ mã hóa Whisper large-v3-turbo với backbone Gemma 4 26B-A4B qua learned projector. Mô hình có khả năng nhận dạng, hiểu lệnh giọng nói, suy luận đa bước (thinking mode) và gọi công cụ (tool use) dưới dạng text, phối hợp với external speech synthesizer để tạo hệ thống đàm thoại 2-stage.

Problem

Xây dựng các trợ lý thoại tương tác và quy trình hỗ trợ khách hàng thường đòi hỏi kết hợp hiểu giọng nói, suy luận phức tạp và gọi công cụ (tool calling) với độ trễ thấp. Các giải pháp mã nguồn mở 2-stage trước đây thường có điểm trải nghiệm đàm thoại hoặc năng lực giải quyết tác vụ (task success) kém xa các hệ thống thương mại Native S2S hoặc gặp khó khăn khi xử lý âm thanh dài và tool use.

Methodology

Mô hình gồm bộ mã hóa Whisper large-v3-turbo kết nối với Gemma 4 26B-A4B thông qua một learned projector. Quá trình huấn luyện diễn ra theo hai giai đoạn: đầu tiên căn chỉnh giao diện giọng nói (align speech interface), sau đó tiếp tục thích ứng projector cùng mô hình nền bằng các tác vụ giọng nói kết hợp cơ chế text replay. Giám sát huấn luyện sử dụng kết hợp cross-entropy loss và teacher distillation tùy theo nguồn dữ liệu. Bộ xử lý tự động chia audio 16 kHz mono thành các chunk 30 giây dùng chung context window với văn bản, cho phép xử lý các đoạn ghi âm dài liên tục tới 30 phút (hỗ trợ cấu hình lên 1 giờ). Checkpoint tạo phản hồi text và tool call dạng cấu trúc, hỗ trợ thinking mode và kết hợp với synthesizer bên ngoài (Cartesia Sonic 3.5).

Setup

Đánh giá hội thoại và tác vụ thoại trên benchmark EVA-A (service accuracy), EVA-X (conversational experience), và \tau-Voice pass@1 kèm độ trễ phản hồi toàn hệ thống. Đánh giá ASR trên LibriSpeech, GigaSpeech, \mu-Bench, FLEURS, Earnings21. Đánh giá suy luận giọng nói trên 8 tập dữ liệu (BFCL, Big Bench Audio, IFEval, MT-Bench, Spoken SQuAD, Alpaca Audio, OpenHermes, GSM8K). Đánh giá văn bản với Gemma 4 26B-A4B trên MMLU-Pro, GPQA Diamond, AIME, MATH-500, AMC 2023, \tau^2. Phục vụ suy luận tối ưu hóa bằng vLLM Docker (docker.io/amant555/vllm_apriel_voice:optimised-26b-v0.32.0) trên 4 GPU H100 80 GB kèm speculative decoding (google/gemma-4-26B-A4B-it-assistant), FlashInfer và FlashAttention-4.

Results

  • Đạt 51.27% EVA-A và 74.13% EVA-X, vượt trội so với các hệ thống mã nguồn mở 2-stage khác như UltraVox v0.6 (8.94% EVA-A, 1.91% EVA-X) và Audex-30B-A3B (5.66% EVA-A, 8.2% EVA-X), đồng thời EVA-X cao hơn cả GPT Realtime 2.1 (61.6%) và Gemini-3.8 Live Extended Thinking (73.5%).
  • Đạt tỷ lệ thành công tác vụ \tau-Voice pass@1 là 65.51% với độ trễ phản hồi trung bình 1.91 giây, tiệm cận GPT Realtime 2.1 (69.82%, 1.55 giây) và tốt hơn đáng kể so với UltraVox v0.6 (26.80%, 3.95 giây).
  • Hiệu năng nhận dạng giọng nói tiếng Anh (WER): đạt 2.23% trên LibriSpeech test-clean, 5.15% trên LibriSpeech test-other, 10.20% trên GigaSpeech, 10.76% trên \mu-Bench (en-US), 3.55% trên FLEURS (en-US) và 11.25% trên Earnings21.
  • Điểm trung bình audio reasoning trên 8 benchmark đạt 85.84 (với GSM8K đạt 93.18, Big Bench Audio đạt 98.90, IFEval đạt 86.47, MT-Bench đạt 86.19, Spoken SQuAD đạt 82.24, BFCL đạt 81.13, OpenHermes đạt 81.8, Alpaca Audio đạt 76.8).
  • Giữ vững năng lực suy luận văn bản so với Gemma 4 26B-A4B gốc (GPQA Diamond: 80.40% vs 77.80%; \tau^2: 70.95% vs 68.93%; MMLU-Pro: 84.42% vs 85.27%).

Limitations

Mô hình không phải là native full-duplex speech-to-speech mà chỉ sinh văn bản và tool calls, cần hạ tầng bên ngoài để tổng hợp âm thanh (TTS) và quản lý chuyển lượt (turn-taking). Hiệu năng đa ngôn ngữ không đồng đều và kém hơn tiếng Anh; giọng nói có nhiễu hoặc mic xa vẫn là thách thức lớn. Âm thanh dài có thể gây lặp từ hoặc mất tính mạch lạc. Khả năng thực thi chính xác chuỗi workflow công cụ phức tạp vẫn có rủi ro sai sót.

Takeaways

Apriel Voice 27B là lựa chọn nguồn mở mạnh mẽ theo kiến trúc 2-stage cho bài toán voice agent và tool calling, đặc biệt khi được tối ưu hóa serving qua vLLM kết hợp speculative decoding trên hạ tầng GPU chuyên dụng.
