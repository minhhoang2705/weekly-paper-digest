Key idea

ringringring là một công cụ mã nguồn mở dạng Model Context Protocol (MCP) cho phép AI agent (như Claude Code hoặc OpenCode) chủ động thực hiện cuộc gọi thoại hai chiều tới điện thoại di động người dùng mà không tốn phí bản quyền hay số điện thoại viễn thông. Dự án tận dụng giao thức SIP thông qua ứng dụng Linphone miễn phí kết hợp với Groq Whisper (STT) và Edge-TTS để xử lý âm thanh thời gian thực.

Problem

Việc tích hợp khả năng AI chủ động gọi điện thoại cho người dùng (voice call notification/dialogue) thường yêu cầu đăng ký nhà mạng (Twilio, SIP trunk), thuê đầu số điện thoại tốn phí theo phút, hoặc phải có tài khoản Apple Developer ($99/năm) và viết ứng dụng iOS CallKit tùy chỉnh phức tạp.

Methodology

Hệ thống hoạt động như một máy chủ stdio MCP trên máy chủ Linux x86_64 chạy cùng AI agent:

  • Giao thức thoại SIP/VoIP: Tích hợp thư viện pjsua2 (pjproject 2.17) qua bản dựng Python 3.11. Client AI chỉ phát lệnh gọi ra (không đăng ký thường trực acfg.regConfig.registrarUri = "") tới SIP account của Linphone trên điện thoại qua TLS proxy (sip:sip.linphone.org;transport=tls) và bắt buộc mã hóa SRTP (acfg.mediaConfig.srtpUse = PJMEDIA_SRTP_MANDATORY).
  • Xuyên NAT (NAT Traversal): Sử dụng STUN server stun.linphone.org:3478 để điều hướng RTP audio qua UDP mà không cần mở port inbound thủ công (kiểm thử chặn UDP 4000-4100 vào máy chủ nhưng vẫn đàm thoại được).
  • Xử lý hội thoại & Barge-in: Cung cấp các công cụ MCP call_start, converse, call_end và skill phone-call. Hỗ trợ ngắt lời (interruption): khi AI đang nói mà người dùng cất giọng, quá trình phát âm thanh lập tức dừng lại và trả về phần văn bản đã/chưa phát cho AI.
  • STT & TTS: Mặc định dùng Groq API (whisper-large-v3-turbo qua chuẩn OpenAI /audio/transcriptions) và Microsoft Edge TTS (zh-CN-YunxiNeural), hỗ trợ cắm script TTS tùy biến qua VOICE_TTS_CMD.
  • Khóa đơn tuyến (Single-line lock): Khóa tài nguyên cuộc gọi để nếu nhiều tác vụ AI cùng gọi trên một máy chủ sẽ trả về trạng thái bận máy (busy).

Setup

Yêu cầu: Máy chủ Linux x86_64 chạy Python 3.11; ứng dụng Linphone trên điện thoại (đã kiểm thử iOS, có thể nhận cuộc gọi khi khóa màn hình hoặc chạy ngầm); 2 tài khoản SIP Linphone miễn phí; Groq API key (STT). Cài đặt thông qua Claude Code plugin (/plugin marketplace add yanyan1115/ringringring) hoặc dòng lệnh install.sh với file wheel pjsua2 biên dịch sẵn.

Results

  • Thời gian tải và cài đặt tự động môi trường thực thi qua plugin lần đầu thực tế mất khoảng 15 giây (实测约 15 秒).
  • Không cung cấp số liệu định lượng chuẩn hóa về WER, MOS hoặc audio latency đo lường chi tiết.

Limitations

Thiếu các số liệu đo kiểm độ trễ end-to-end (STT + LLM + TTS + RTP) và độ chính xác nhận dạng giọng nói; phụ thuộc hoàn toàn vào hạ tầng SIP miễn phí của linphone.org; gói binary pjsua2 chỉ dựng sẵn cho Linux x86_64 Python 3.11 (macOS/Docker cần biên dịch thủ công); dễ bị lỗi gián đoạn do VPN/proxy trên điện thoại không chuyển tiếp UDP.

Takeaways

Cung cấp giải pháp kỹ thuật hữu ích và tiết kiệm để triển khai voice agent gọi điện thoại thông qua kiến trúc MCP kết hợp chuẩn SIP/STUN hiện có.
