README: pitupitu Talk to your coding agents, on any of your machines. Start, check on and unblock your coding agents (Claude Code, Codex, Kiro CLI, OpenCode, pi, Qwen Code, Cline, Kilo Code and others) by voice, from the iPhone or Android app or any browser. Your agents run on the subscriptions you already pay for: Claude Code on your Claude plan, Codex on your ChatGPT plan. No API keys. This is the open-source agent that links each of your machines to pitupitu . Website · Install · How it works · Commands · Protocol · Privacy · Security --- You say what you want done and where. pitupitu starts the agent session on that machine, keeps an eye on it, answers what it can, and tells you when it is done or needs you. In the car, on a walk, at the desk: the same sessions, from your phone or any browser. pitupitu runs your agents in Herdr TUI, herdr's terminal app: a terminal workspace manager for coding agents, the herdr command. Open herdr on that machine and you see exactly what your phone sees: the same sessions, live, to watch or type into at the desk. herdr has to be open on that machine for pitupitu to reach your agents: you open it in a terminal and leave it open, and pitupitu connects to it. If it is not installed, pitupitu setup offers to install it. The Herdr desktop app is a separate program on its own runtime: pitupitu does not use it, and sessions pitupitu starts do not appear in it. This repository is the part that runs on each of your machines: a small Rust agent that links the machine to pitupitu cloud over one outbound WebSocket. The conversation, the voice, the apps and the page at pitupitu.chat are the hosted service. Talk. Say it; it starts. The line above the microphone names what needs you. Work. What needs you first, then what runs, on every machine. A session that asks. The question at the top, the answers as buttons, the terminal under it. On a wide screen. The work beside the conversation; open herdr on the machine for the same sessions in your terminal.

Key idea

pitupitu là một agent mã nguồn mở viết bằng Rust, đóng vai trò cầu nối liên kết máy tính cục bộ với dịch vụ đám mây pitupitu qua WebSocket một chiều. Hệ thống cho phép lập trình viên điều khiển, theo dõi và giải quyết tắc nghẽn cho các coding agent (như Claude Code, Codex, OpenCode) bằng giọng nói từ điện thoại (iOS, Android) hoặc trình duyệt mà không cần mở port hay chia sẻ API key.

Problem

Các coding agent như Claude Code hoặc OpenAI Codex chạy trực tiếp trong terminal cục bộ và yêu cầu tương tác bằng bàn phím tại chỗ. Lập trình viên khó có thể theo dõi tiến độ, kiểm tra trạng thái hoặc phản hồi các câu hỏi chặn (blocking questions) của agent khi đang di chuyển (lái xe, đi bộ) hoặc không ngồi trực tiếp tại bàn làm việc.

Methodology

Kiến trúc hệ thống bao gồm một box agent cục bộ viết bằng Rust kết nối ra ngoài (dial out) tới máy chủ cloud qua wss://api.pitupitu.chat/v1/box. Box agent tương tác với các coding agent thông qua bộ quản lý không gian làm việc terminal Herdr TUI (lệnh herdr). Khi người dùng ra lệnh bằng giọng nói qua app di động/web, cloud gửi các lệnh RPC cố định xuống box agent (liệt kê, mở/đóng tab, gửi phím/prompt, đọc màn hình, đợi agent). Box agent thu thập ngữ cảnh bằng cách quét log cục bộ trong 7 ngày gần nhất (tối đa 300 phiên) từ nhiều định dạng log agent khác nhau (JSONL của Claude Code/Codex/pi/Qwen, SQLite read-only của OpenCode/Kilo Code). Dữ liệu gửi lên cloud được thu gọn (user prompt tối đa 1000 ký tự, phản hồi tối đa 600 ký tự, session tối đa 32 KB) và tự động ẩn (redact) các chuỗi nhạy cảm như token sk-..., ghp-... hoặc mật khẩu.

Setup

Yêu cầu cài đặt trên macOS (Intel, Apple Silicon) hoặc Linux (x86_64, arm64, static musl) thông qua script cài đặt, Homebrew (klarluft/tap/pitupitu), hoặc cargo install. Yêu cầu cài đặt sẵn Herdr TUI và các CLI coding agent (Claude Code, Codex, Kiro CLI, OpenCode, pi, Qwen Code, Cline, Kilo Code). Quản lý tiến trình nền qua systemd (systemd --user) trên Linux hoặc launchd trên macOS. Đăng nhập và ghép nối thiết bị qua mã xác thực/QR code.

Results

  • Không có số liệu đo lường định lượng (như WER, MOS, độ trễ xử lý giọng nói, tài nguyên RAM/CPU tiêu thụ) được công bố trong tài liệu.

Limitations

Xử lý giọng nói (STT, TTS, agent orchestration) phụ thuộc hoàn toàn vào dịch vụ đám mây đóng pitupitu.chat. Bắt buộc phải duy trì tiến trình terminal herdr chạy ngầm để kết nối với các coding agent. Box agent chỉ hỗ trợ tập lệnh RPC định sẵn, không hỗ trợ shell tự do. Chưa có đánh giá benchmark về độ trễ điều khiển thời gian thực qua mạng di động.

Takeaways

Cung cấp một mẫu kiến trúc tham khảo tốt (outbound WebSocket kết hợp terminal multiplexer cục bộ) để tích hợp giao diện voice-first trên di động với các CLI tool nội bộ mà không cần VPN, dynamic DNS hay mở cổng mạng.
