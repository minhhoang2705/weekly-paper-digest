README excerpt

Robô de bancada com ESP32: rosto animado no OLED, conversa por voz em pt-BR, jogos e controle do Mac README: Cozmo ESP32. *Rodando na bancada. Vídeo em melhor qualidade.* Um robozinho de bancada com rosto animado num OLED, que conversa por voz em português, controla o Mac e joga pedra-papel-tesoura. Feito com um ESP32 de R$ 40 e peças de marketplace. O ESP32 cuida do corpo (rosto, luzes, som, braço, sensores) e o navegador do celular ou do Mac cuida da conversa, falando direto com a API de voz. Assim o ESP32 nunca precisa processar áudio. O que ele faz. - Rosto animado: olhos que piscam, olham em volta, mudam de humor e "respiram" no ritmo da fala. - Conversa por voz em pt-BR: você fala, ele responde falando, com interrupção de turno automática. - Dados reais, sem inventar: hora, temperatura e cotação de criptomoedas vêm de fontes de verdade, entregues ao modelo como contexto. Ele não chuta números. - Expressões e luzes por voz: "fica feliz", "acende a luz vermelha", "pisca a amarela". - Braço servo: acena, gira, dança. - Pedra, papel e tesoura: contagem no semáforo, jogada sorteada pelo hardware, placar calculado no ESP32 (o modelo não decide quem ganhou). - Controle do Mac: abre apps e sites, pesquisa no Google e no YouTube. - Cria páginas web por voz: escreve o HTML, abre no VS Code e no Chrome, e edita ao vivo ("troca o fundo pra azul") com o navegador recarregando sozinho. - WhatsApp por voz: escreve a mensagem no chat aberto e só envia depois de você confirmar falando. Como funciona. O ESP32 sobe um servidor web na rede local. A página que ele serve é a interface: botões de humor, caixa de texto e o botão de conversa. Toda a parte de áudio acontece no navegador. Hardware. Exatamente o que foi usado na montagem. Key idea

Dự án mã nguồn mở chế tạo trợ lý robot để bàn chi phí thấp mô phỏng Cozmo, sử dụng vi điều khiển ESP32 và linh kiện phổ thông. Kiến trúc phân tách việc điều khiển phần cứng (OLED, servo, cảm biến) trên ESP32 và đẩy toàn bộ xử lý thoại (ASR, LLM, TTS) sang trình duyệt web kết nối với Deepgram Voice Agent và OpenAI API.

Problem

Vi điều khiển giá rẻ như ESP32 bị giới hạn nghiêm trọng về bộ nhớ RAM và năng lực tính toán để xử lý pipeline âm thanh thời gian thực (nhận dạng giọng nói, streaming audio, suy luận LLM và tổng hợp giọng nói). Việc chạy trực tiếp các mô hình AI giọng nói trên chip đòi hỏi phần cứng phức tạp và đắt tiền hơn.

Methodology

Hệ thống áp dụng mô hình phân tách chức năng:

  • ESP32: Khởi tạo web server nội mạng phục vụ UI điều khiển; điều khiển màn hình OLED I2C 0.96 inch hiển thị animation mắt ("thở" theo nhịp nói, chớp mắt), mô-đun LED giao thông, còi buzzer chủ động, servo SG90 360 độ điều khiển cánh tay và cảm biến âm thanh KY-037 / nút bấm. ESP32 tự quản lý logic trò chơi oẳn tù tì (sinh số ngẫu nhiên phần cứng và tính điểm).
  • Trình duyệt (Mac/Mobile): Thu âm giọng nói và phát audio trực tiếp qua WebSocket đến Deepgram Voice Agent. Deepgram chịu trách nhiệm transcription, chuyển tiếp ngữ cảnh tới gpt-4o-mini để suy luận và phát âm phản hồi tiếng Bồ Đào Nha (pt-BR) qua OpenAI TTS.
  • Function Calling & Tích hợp: Trình duyệt điều hướng lệnh gọi hàm: gửi HTTP request tới ESP32 để kích hoạt biểu cảm/chuyển động, và gọi tới script cầu nối Python (mac/cozmo_mac.py chạy cục bộ trên 127.0.0.1) để điều khiển macOS (mở ứng dụng, soạn thảo/sửa đổi trang web HTML theo thời gian thực, gửi tin nhắn WhatsApp có xác nhận bằng giọng nói hai bước).

Setup

Cấu hình phần cứng: ESP32 WROOM-32 (30 chân), màn hình OLED I2C SSD1306, mô-đun đèn LED giao thông, buzzer 5V, micro servo SG90 360°, cảm biến âm thanh KY-037. Thư viện Arduino: Adafruit SSD1306, Adafruit GFX, ArduinoJson (v7), ESP32Servo. Phía trình duyệt yêu cầu cờ Chrome Insecure origins treated as secure để cấp quyền microphone qua HTTP. Kết nối API yêu cầu OpenAI API key và Deepgram API key.

Results

  • Không có số liệu benchmark định lượng (độ trễ RTF, WER, MOS) được báo cáo trong tài liệu.
  • Chi phí phần cứng ESP32 được công bố vào khoảng R$ 40 cùng các linh kiện phổ thông từ marketplace.

Limitations

Không hỗ trợ ngắt lời (barge-in / full-duplex) khi robot đang nói vì micro bị ngắt gửi âm thanh để tránh dội âm thanh từ loa vào mic; âm thanh hội thoại phát ra từ điện thoại/Mac thay vì từ chính robot; servo quay 360 độ liên tục nên điều khiển góc quay chỉ dựa vào thời gian (open-loop, không có phản hồi vị trí); Deepgram TTS chưa hỗ trợ tiếng Bồ Đào Nha nên phải dùng OpenAI TTS; tính năng đo mực nước bằng cảm biến HC-SR04 chưa hoạt động hoàn chỉnh.

Takeaways

Một kiến trúc thực tế cho các dự án IoT voice agent giá rẻ: tận dụng trình duyệt trên điện thoại hoặc máy tính làm trạm trung gian xử lý media và WebSockets giúp giải phóng ESP32 khỏi tải tính toán âm thanh, trong khi vẫn cho phép LLM điều khiển trực tiếp các bộ chấp hành phần cứng qua HTTP function calling.
