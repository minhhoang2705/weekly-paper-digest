Key idea

IP Bot là một ứng dụng máy tính (desktop workbench) mã nguồn mở kết hợp Electron, Vue 3 và backend Express/SQLite để tự động hóa toàn bộ quy trình tạo video người số (digital human). Hệ thống liên kết từ khâu bóc tách/viết lại kịch bản, tổng hợp giọng nói (TTS), dựng hình người số, biên tập hậu kỳ video (subtitles, BGM) đến hỗ trợ phát hành đa nền tảng.

Problem

Quy trình tạo video phát thanh/thuyết trình bằng người số (digital human monologue) thường phân mảnh, đòi hỏi người dùng phải thao tác thủ công qua nhiều công cụ riêng biệt (công cụ viết kịch bản, phần mềm TTS, dịch vụ dựng hình người số, trình dựng video, công cụ tạo phụ đề và giao diện tải lên mạng xã hội).

Methodology

IP Bot xây dựng một pipeline tích hợp trên desktop:

  • Giao diện & Desktop Layer: Sử dụng Vue 3, TypeScript, Pinia, Arco Design, Electron IPC, kết hợp better-sqlite3, Sharp, Playwright, FFmpeg và các script Python (bao gồm MODNet).
  • Backend quản trị: Express, SQLite, bcryptjs, JWT để quản lý tài khoản, thiết bị, quota và lưu cấu hình API dịch vụ.
  • Quy trình 9 bước: (1) Trích xuất kịch bản tham khảo từ video; (2) Viết lại/tái cấu trúc nội dung; (3) Tổng hợp giọng nói (hỗ trợ voice clone, tích hợp CosyVoice / mô hình đa phương thức); (4) Tạo video người số qua API đám mây hoặc dịch vụ local; (5) Tự động nhận diện và ghép phụ đề; (6) Ghép nhạc nền và mix âm thanh; (7) Sinh tiêu đề và thẻ tag; (8) Tạo ảnh bìa video; (9) Kết nối xuất bản tự động lên Douyin, WeChat Channels, Kuaishou, Xiaohongshu qua automation script.

Setup

Nền tảng đã kiểm chứng: Windows x64. Yêu cầu môi trường Node.js 22.x (npm 10+), FFmpeg, Python nhúng, Chromium (Playwright). Người dùng tự cấu hình API nhà cung cấp: Aliyun Bailian / OSS, Volcengine, RunningHub hoặc dịch vụ người số local. Không kèm sẵn trọng số mô hình hoặc file nhị phân trong kho mã nguồn.

Results

  • Tài liệu không cung cấp bất kỳ kết quả định lượng cụ thể nào (như WER, MOS, FPS, thời gian render hay tỷ lệ thành công của tác vụ).

Limitations

Kho mã nguồn chỉ cung cấp giao diện và orchestration logic; hoàn toàn không đính kèm model weights, FFmpeg/DLL, Python runtime hay tài nguyên media do vấn đề bản quyền. Đang ở trạng thái Developer Preview, còn cảnh báo bảo mật về dependencies và lỗi TypeScript thừa hưởng từ upstream. Tính năng đăng tải mạng xã hội chưa được kiểm chứng end-to-end trên mọi nền tảng và dễ bị ảnh hưởng bởi cơ chế chống bot/thay đổi giao diện.

Takeaways

Dự án hữu ích như một mẫu tham khảo kiến trúc kỹ thuật (system integration blueprint) cho việc đóng gói các pipeline AI đa phương thức (LLM + TTS + Talking Head + FFmpeg) thành ứng dụng desktop thương mại hoặc nội bộ.
