The Agentic-Native Operating System README: Veda. The Agentic-Native Operating System An operating system written in Rust, with a voice agent built into the system. Screenshots · Quick start · Make an app agentic · Architecture · Documentation Say *"Hey Veda, switch my wallpaper to the dunes"* and it is done. The agent works in every application through the same code as your keyboard and mouse, and asks you before anything that is hard to undo. Everything here is Rust, from the UEFI bootloader and the microkernel to the window system and the applications. An agent in the system A service from boot that wakes when you say its name. Its model, its voice and even its name are settings. Actions, not screen scraping Applications declare typed actions that run the same code as the keyboard and mouse. The built-in ones offer more than 100. Consent the model cannot skip The system holds sensitive and destructive actions until you allow them, and only the desktop shell can answer. A microkernel in Rust Capabilities, SMP, and services in user space that restart by themselves. Applications get Rust's standard library. Linux's drivers, contained Linux drives the hardware in a VM on Veda's own hypervisor, held in by the IOMMU and restarted if it crashes. A complete desktop A compositing window system, a lock screen, a web browser on WebKit, OpenGL ES 3.0, GCC in the Terminal, WPA3 Wi-Fi and a firewall that asks first. Screenshots. Key idea

Veda là một hệ điều hành hoàn chỉnh viết bằng Rust với voice agent được tích hợp trực tiếp như một dịch vụ hệ thống chạy từ lúc khởi động. Thay vì sử dụng screen scraping, agent tương tác với các ứng dụng thông qua giao thức typed actions và cơ chế phân quyền, xin phép (consent) an toàn được quản lý bởi desktop shell.

Problem

Các trợ lý giọng nói và AI agent trên máy tính hiện nay thường là ứng dụng tầng người dùng hoạt động tách biệt, phụ thuộc vào screen scraping hoặc accessibility API vốn chậm, kém ổn định và dễ gây lỗi. Hơn nữa, chúng thiếu sự kiểm soát an toàn cấp hệ điều hành đối với các tác vụ nhạy cảm hoặc mang tính phá hủy dữ liệu.

Methodology

Veda thiết kế một kiến trúc agentic-native từ tầng sâu nhất của hệ điều hành:

  • Voice Agent Service: Chạy như một system service từ khi boot, hỗ trợ đánh thức bằng wake word "Hey Veda", phím tắt Super+Space hoặc biểu tượng taskbar. Agent cấu hình API key (Deepgram) để xử lý STT, TTS và LLM trong phần cài đặt Settings.
  • Typed Actions qua UI Toolkit: Các ứng dụng được xây dựng trên UI toolkit của Veda (ui::App) định nghĩa hành động thông qua agent_info (danh sách action, tham số, mô tả, mức độ rủi ro Risk::Destructive), báo cáo trạng thái bằng agent_state và xử lý lệnh qua agent_invoke. Agent tương tác cùng đường dẫn mã nguồn như chuột và bàn phím thay vì đọc màn hình.
  • Kiểm soát Consent không thể vượt qua: Hệ điều hành giữ lại các hành động có rủi ro cao hoặc nhạy cảm để chờ người dùng phê duyệt; chỉ có desktop shell mới có quyền trả lời prompt này.
  • Kiến trúc OS: Microkernel viết bằng Rust hỗ trợ capabilities, SMP và IPC; các dịch vụ user-space có cơ chế tự khởi động lại khi crash. Driver phần cứng chạy trên một Linux VM được cách ly bằng IOMMU thông qua hypervisor riêng của Veda.

Setup

Hỗ trợ máy tính x86-64 và QEMU (yêu cầu KVM với nested virtualization kvm_intel nested=1). Cần Rust, công cụ build (GCC, musl, CMake, NASM, Python3, v.v.). Chạy thực tế trên PC qua USB live (UEFI, bật VT-x/VT-d, tắt Secure Boot). Yêu cầu Deepgram API key để kích hoạt agent.

Results

  • Hơn 100 typed actions được tích hợp sẵn trên toàn bộ các ứng dụng mặc định của hệ thống
  • Thời gian biên dịch toolchain (GCC, musl, Rust cho Veda): khoảng 30 phút
  • Thời gian biên dịch WebKit (trình duyệt web): 1 giờ hoặc hơn
  • Độ trễ (latency), WER, MOS: Không được nêu trong tài liệu

Limitations

Agent phụ thuộc vào dịch vụ API đám mây bên thứ ba (Deepgram) để hoạt động, không chạy offline/on-device cho pipeline tiếng nói; yêu cầu phần cứng x86-64 hỗ trợ ảo hóa phần cứng cụ thể (VT-x, VT-d) và phải tắt Secure Boot; tài liệu hoàn toàn thiếu các số liệu benchmark định lượng về hiệu năng tác vụ của agent.

Takeaways

Veda minh chứng một hướng đi tiềm năng cho AI-native OS: thay thế screen scraping bằng typed action APIs tích hợp trực tiếp vào UI framework và hệ thống cấp phép microkernel, giúp voice agent điều khiển ứng dụng ổn định và an toàn hơn.
