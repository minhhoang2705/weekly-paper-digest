Claude Code skill: faceless 9:16 explainer reels in a cut-paper style. Voice-timed scenes, word-by-word captions. Free, local, no API keys. README: paper-reel. A Claude Code skill that makes faceless 9:16 explainer reels in a cut-paper style: flat textured paper shapes, a box mascot in a different hat every scene, a screwed-on headline sign, rubber stamps, counters, and captions that pop in one paper scrap per word. You give Claude a topic, it writes six or seven lines, and one command renders the MP4. Watch the example reel (23 s, made with this skill, about the khan-explainer skill). Write-up: paper-reel: a free Claude Code skill that draws cut-paper explainer reels from one prompt. How the skill explains itself, on YouTube: wide cut and Short. Everything is drawn in code and runs on your Mac: Kokoro for the voice, whisper.cpp for word timing, an HTML canvas, Playwright and ffmpeg. No API keys, no accounts, no editor. How it stays in sync. The voice is the clock. Every spoken line is one scene, with a hard cut just before the line starts. After the voice is generated, whisper.cpp times every word, and the scenes cue props off those words: a stamp slams on "free", a counter runs up on "stars", the mascot's face changes on the payoff. Install. You need macOS, Node 18 or newer, ffmpeg and whisper.cpp. doctor checks every piece and prints the exact command for anything missing: the whisper model, a Python with kokoro-onnx, and the Kokoro model files. Use. Ask Claude Code: > Make a paper-reel about uv, the Python package manager. CTA keyword UV. > Make a skill-spotlight reel for this repo, comment keyword REPO. Claude drafts the script for you to approve, generates the voice, builds one scene per line, checks the frames and exports. Or run the pipeline yourself: An export renders 1080x1920 at 30 fps with a ducked lo-fi bed at about -14 LUFS, in about 30 seconds on an M-series Mac. SKILL.md is the full reference: the script arc, the scene rules, the kit API and the gotchas. references/style.md has the palette and layout grid. Credits. Made by Haider Farooq. MIT licensed. Key idea

paper-reel là một Claude Code skill cho phép tự động tạo video ngắn dạng giải thích (explainer reels) tỉ lệ 9:16 theo phong cách cắt giấy (cut-paper style). Toàn bộ quy trình chạy hoàn toàn cục bộ trên macOS bằng cách kết hợp Kokoro TTS, whisper.cpp để lấy mốc thời gian từng từ, HTML canvas vẽ hoạt ảnh qua Playwright và ffmpeg đóng gói MP4.

Problem

Việc tạo các video ngắn giải thích có hoạt họa thường đòi hỏi phần mềm dựng video phức tạp, chi phí API đám mây, hoặc chỉnh sửa thủ công để đồng bộ hình ảnh khớp với giọng đọc.

Methodology

Hệ thống sử dụng nguyên lý 'voice is the clock' (giọng nói là đồng hồ chủ đạo):

  • Kịch bản & Lời thoại: Claude Code soạn kịch bản gồm 6–7 dòng tương ứng với 6–7 phân cảnh (mỗi dòng đọc là một cảnh cắt dứt khoát).
  • TTS & Căn chỉnh thời gian: Kokoro TTS (thông qua kokoro-onnx) tạo giọng lồng tiếng cục bộ. Sau đó, whisper.cpp phân tích âm thanh để xác định mốc thời gian chính xác của từng từ (t_0).
  • Render hoạt ảnh: Hoạt ảnh được định nghĩa và vẽ bằng code trên HTML canvas (kế thừa từ thư viện animate của cth9191), kích hoạt các đạo cụ (con dấu dập, bộ đếm số, đổi biểu cảm mascot, dán chữ theo từng từ) khớp với thời gian phát âm của từ tương ứng (VW(scene, word).t0).
  • Xuất video: Playwright tự động hóa trình duyệt Chromium để chụp từng khung hình canvas, sau đó ffmpeg kết hợp hình ảnh, giọng đọc và nhạc nền (lo-fi ducked bed).

Setup

Hệ điều hành macOS, Node.js 18 trở lên, Python (chạy kokoro-onnx), ffmpeg, whisper-cpp, mô hình Kokoro và mô hình Whisper. Quy trình thực hiện qua CLI reel (các lệnh new, voice, still, check, export) hoặc qua câu lệnh điều khiển trực tiếp từ Claude Code.

Results

  • Xuất video chuẩn độ phân giải 1080x1920 (9:16) ở tốc độ 30 fps.
  • Thời gian render hoàn tất một video mất khoảng 30 giây trên máy Mac dòng M (Apple Silicon).
  • Âm thanh nền (lo-fi bed) được ducking tự động ở mức khoảng -14 LUFS.

Limitations

Chỉ hỗ trợ hệ điều hành macOS; yêu cầu thiết lập nhiều phụ thuộc hệ thống (ffmpeg, whisper-cpp, Python, Node); tài liệu không cung cấp các số liệu benchmark định lượng về độ chính xác thời gian (alignment error) hay đánh giá chất lượng giọng đọc.

Takeaways

Sử dụng ASR cục bộ (whisper.cpp) để trích xuất word-level timestamps làm timeline đồng bộ hoạt ảnh canvas theo TTS là một giải pháp kỹ thuật hiệu quả, tiết kiệm chi phí và có tính tự động hóa cao cho video generation.
