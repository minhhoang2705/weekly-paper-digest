Summary

model card excerpt

Confucius4-R2T2: A Low Latency and High Accuracy Real-Time Speech Recognition Model Real Real-Time Transcription Confucius4-R2T2 is a low-latency and high-accuracy true streaming Automatic Speech Recognition (ASR) model that features fine-grained and configurable decoding chunks from 80 ms to 2 s. The model operates in append-only output mode: committing transcript text permanently without revising previous words, which is critical for applications where text must be processed or acted upon instantly. This results in a smoother user experience, avoiding disruptive text revisions and visual flickering in real-time applications, such as Real-Time Live Captioning & Subtitling, Downstream NLP Pipelines & LLM Agents, Simultaneous Speech Translation, etc. R2T2, short for Real Real-Time Transcription, is built upon the Qwen3-ASR model. And it is trained with a unique set of data construction techniques including stable-prefix data, forced time-alignment data, and token-level audio segmentation. Combined with a Longest Stable Prefix (LSP) learning paradigm (tech report will be released soon), R2T2 can dynamically determine when a stable prefix can be safely emitted and when additional audio context is needed. By exposing only stable prefixes, the model provides high-quality context that conditions subsequent predictions while guaranteeing that previously emitted text remains unchanged. Despite its streaming design, R2T2 maintains strong accuracy in offline recognition. - Low-latency and high accuracy streaming recognition — The model achieves accuracy close to that of offline recognition, with only 200 to 600 milliseconds average latency. - Stable streaming output — Emitted text is committed as it arrives and remains unchanged. - Configurable low-latency chunking - Supports decoding chunks from 80 ms to 2 s for different latency/accuracy trade-offs. - No loss in offline accuracy — Adding streaming support does not degrade offline recognition accuracy. - vLLM backend — Provi

Key idea

Confucius4-R2T2 là mô hình ASR true streaming phát triển bởi NetEase Youdao dựa trên Qwen3-ASR-1.7B, hỗ trợ chunk giải mã tùy biến từ 80 ms đến 2 s với độ trễ trung bình 200–600 ms. Mô hình áp dụng cơ chế append-only (cam kết văn bản vĩnh viễn, không chỉnh sửa lại token đã phát) giúp loại bỏ hiện tượng nhấp nháy chữ trên giao diện và tương thích trực tiếp với các pipeline NLP/LLM agent thời gian thực.

Problem

Các mô hình pseudo-streaming ASR thông thường liên tục chỉnh sửa văn bản đã xuất ra (text revisions), gây giật nhấp nháy thị giác khó chịu trong hiển thị phụ đề trực tiếp và phá vỡ chuỗi xử lý của các hệ thống downstream như Simultaneous Speech Translation hoặc LLM Agent vốn yêu cầu văn bản đầu vào ổn định theo thời gian thực.

Methodology

Xây dựng trên nền tảng Qwen3-ASR (base model: Qwen/Qwen3-ASR-1.7B). Mô hình được huấn luyện bằng tập kỹ thuật kiến tạo dữ liệu đặc thù bao gồm: dữ liệu tiền tố ổn định (stable-prefix data), dữ liệu căn chỉnh thời gian cưỡng bức (forced time-alignment data), và phân đoạn âm thanh mức token (token-level audio segmentation). Kết hợp cùng mô hình học Longest Stable Prefix (LSP), R2T2 xác định động thời điểm tiền tố đã an toàn để phát ra và thời điểm cần thêm ngữ cảnh âm thanh tương lai. Mô hình vận hành ở chế độ append-only, hỗ trợ context/hotword prompt, backend tối ưu thông lượng cao vLLM và backend Transformers.

Setup

Đánh giá trên 9 tập kiểm thử tiếng Anh (AMI, Giga-clean, LibriSpeech-clean, LibriSpeech-other, SPGI, VoxPopuli, Earnings22, TED-LIUM, EN-RealSI) dùng WER (%) và 5 tập kiểm thử tiếng Trung (Wenet-net, Wenet-meeting, SPEECHIO-06, SPEECHIO-07, CN-RealSI) dùng CER (%). So sánh ở cấu hình chunk 160 ms với Qwen3-ASR base (160ms), pseudo-streaming Qwen3-ASR (2s/u2/t5), X-ASR (160ms), WhisperRT (200ms), Nemotron (160ms), Voxtral (160ms) và 3 hệ thống thương mại (AssemblyAI, Commercial A, Commercial B). Hỗ trợ suy luận qua vLLM, tích hợp sẵn WebSocket server kết hợp VAD (Stream-VAD từ FireRedVAD).

Results

  • Ở cấu hình 160 ms chunk trên tiếng Anh, R2T2 đạt WER vượt trội so với Qwen3-ASR base 160ms: AMI đạt 11.37% (so với 24.79%), LS-clean đạt 2.13% (so với 22.30%), LS-other đạt 4.88% (so với 25.74%), Earnings22 đạt 9.36% (so với 29.72%).
  • Vượt qua tất cả các mô hình open-source true-streaming 160 ms trên toàn bộ các benchmark tiếng Anh (ví dụ trên VoxPopuli: R2T2 đạt 3.07% vs X-ASR 5.68%, Nemotron 5.69%, Voxtral 6.30%).
  • Trên tiếng Trung ở chunk 160 ms, R2T2 vượt xa Qwen3-ASR base 160ms trên mọi tập dữ liệu: Wenet-net đạt CER 5.87% (vs 19.79%), Wenet-meeting đạt 7.27% (vs 20.38%), SPEECHIO-06 đạt 7.30% (vs 24.50%), SPEECHIO-07 đạt 8.20% (vs 21.16%), CN-RealSI đạt 3.48% (vs 39.72%).
  • Đạt độ chính xác cạnh tranh trực tiếp với các hệ thống thương mại đóng (pseudo-streaming): trên CN-RealSI, R2T2 đạt 3.48% CER, tốt hơn Commercial A (3.99%) và Commercial B (3.64%).

Limitations

Chi tiết toán học và thuật toán huấn luyện của cơ chế Longest Stable Prefix (LSP) chưa được công bố chi tiết trong tài liệu (hứa hẹn trong technical report sắp tới). Dù hỗ trợ đa ngôn ngữ (Pháp, Đức, Nhật, Hàn,...), tài liệu chưa cung cấp số liệu đánh giá định lượng cho các ngôn ngữ ngoài tiếng Anh và tiếng Trung. Kích thước tập dữ liệu huấn luyện và chi phí compute không được nêu.

Takeaways

Là lựa chọn mã nguồn mở hàng đầu hiện nay cho các hệ thống streaming ASR cần độ trễ thấp (160 ms chunk, 200–600 ms latency) và yêu cầu tính nhất quán đầu ra (append-only không giật sửa từ). Sẵn sàng triển khai production nhờ tích hợp trực tiếp vLLM, Docker container và kiến trúc WebSocket kết hợp VAD.
