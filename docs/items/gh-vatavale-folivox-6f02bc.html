Turn any e-book into a chaptered audiobook in your own voice: free, fully local. CosyVoice 3 or Fish Audio Drama 3 (80+ languages, several voices), no cloud needed README: Folivox. The audiobook workhorse. A powerful tool in a simple interface, free. Drop in a book, pick a voice, press Render. Get a chaptered audiobook read in any voice you like, on your own computer. FB2 · EPUB · DOCX · PDF · TXT → .m4b / .mp3 with chapters, cover and metadata What is this. Folivox turns a whole book, many hours of it, into a finished audiobook. Out of the box it reads with CosyVoice 3, an open model that clones a voice from a short sample, running entirely on your machine: no account, no subscription, no per-character fee, nothing uploaded. It is one application with many engines behind it. The book can be read by the free local CosyVoice 3, by the local Fish Audio Drama 3 (80+ languages, several voices in one scene; needs a Mac with enough memory), or by ElevenLabs, OpenAI, Gemini, Cartesia or Fish Audio online with your own API key. A narrator voice can come from the bundled catalog, from your own recording, or be designed for this particular book. Everything around the voice, from text clean-up to quality control, chapters and a crash-safe journal, is the same whichever engine you choose. Use the web studio (folivox ui, in 49 interface languages) or the command line: same pipeline, same results. Quick start. 1. Install. Pick one way. Each needs no administrator rights and is safe to run again. One command (recommended). Open a terminal (macOS: Terminal in Applications → Utilities; Windows: PowerShell from the Start menu; Linux: any terminal), paste the line for your system and press Enter. macOS and Linux: Windows (PowerShell): With git (if you want the source code) macOS and Linux: Windows (PowerShell): With Docker (home server or NAS) Optional, not needed on a normal computer. Create a stack from docker-compose.yml (or docker-compose.nvidia.yml for an NVIDIA GPU), set FOLIVOX_UI_TOKEN to a password, deploy and open http:// :8765/. Key idea

Folivox là một công cụ mã nguồn mở giúp chuyển đổi sách điện tử thành sách nói có đầy đủ chương mục, metadata và cover, hoạt động cục bộ hoặc qua API đám mây. Dự án tích hợp mô hình CosyVoice 3 mặc định để zero-shot clone giọng đọc từ mẫu ngắn mà không tốn phí, đồng thời hỗ trợ Fish Audio Drama 3 cùng nhiều nhà cung cấp online.

Problem

Việc tạo audiobook dài nhiều tiếng (long-form TTS) từ các định dạng sách khác nhau thường gặp khó khăn về chi phí API đắt đỏ, thiếu khả năng xử lý ngắt quãng/lỗi mạng (crash-recovery), chuẩn hóa văn bản kém tự nhiên (số, ngày tháng, biến cách) và không có cơ chế tự động kiểm soát chất lượng (QC) cho từng đoạn âm thanh.

Methodology

Hệ thống xây dựng một pipeline hoàn chỉnh bao gồm:

  • Parser & Text Normalization: Hỗ trợ FB2, EPUB, DOCX, PDF (text layer), TXT; loại bỏ header/footer PDF và unhyphenate; chuẩn hóa số, ngày, tiền tệ, đơn vị, chữ số La Mã kèm ngữ pháp/biến cách cho 9 ngôn ngữ (Russian, English, German, French, Spanish, Italian, Chinese, Japanese, Korean) và phục hồi ё/dấu trọng âm tiếng Nga bằng ruaccent.
  • Audio Engines: Chạy offline mặc định với CosyVoice 3 (voice cloning từ mẫu 6–15 giây) hoặc Fish Audio Drama 3 (hỗ trợ chỉ đạo bằng văn bản [calm, warm narration], hơn 80 ngôn ngữ, hội thoại đa giọng), hoặc kết nối API ngoài (ElevenLabs, OpenAI, Gemini 3.8 Flash, Cartesia, Fish Audio).
  • Voice Design & QC: Cho phép trích xuất giọng từ video/file âm thanh dài, thiết kế giọng bằng LLM + Gemini/Qwen3 TTS. Sử dụng Whisper (faster-whisper hoặc mlx-whisper) nghe lại từng fragment để kiểm tra lỗi; tự động đọc lại và chọn take tốt nhất (--takes, mặc định 3).
  • Journaling & Packaging: Ghi nhật ký từng fragment đã render để khôi phục khi gặp sự cố, chuẩn hóa âm lượng (−18 LUFS) và đóng gói thành 1 file .m4b (kèm chapter markers, cover, metadata) hoặc từng file .mp3 theo chương.

Setup

Yêu cầu Python 3.10–3.12, ffmpeg, dung lượng tải model khoảng 7.6 GB (~6 GB model giọng và ~1.6 GB model QC). Hỗ trợ phần cứng đa dạng: macOS Apple Silicon (GPU qua Metal, MLX cho Whisper), NVIDIA CUDA, hoặc CPU (có fallback CPU khi GPU lỗi). Cung cấp giao diện web studio (folivox ui) hỗ trợ 49 ngôn ngữ và CLI (folivox render). Cài đặt qua script một dòng, Docker hoặc git.

Results

  • Chi phí tạo voice sample online bằng Gemini 3.8 để làm cloning prompt cho engine local: khoảng $0.0023 cho 10 giây audio.
  • Chi phí render toàn bộ sách online bằng Gemini 3.8 Flash TTS: ước tính khoảng 0.8 mỗi giờ audio tại thời điểm tháng 10/2026 (~8 cho cuốn sách 10 giờ).

Limitations

Tài liệu đang ở trạng thái 'early development'. Không cung cấp số liệu benchmark chuẩn hóa (WER, CER, MOS, RTF cụ thể cho từng phần cứng). Mô hình Fish Audio Drama 3 cục bộ đòi hỏi máy Mac có đủ bộ nhớ; PDF chỉ đọc layer text, không hỗ trợ OCR; hỗ trợ card đồ họa AMD và Intel còn ở mức thử nghiệm (thông qua native runtime audio.cpp).

Takeaways

Folivox cung cấp một framework kỹ thuật hoàn chỉnh cho kỹ sư speech giải quyết bài toán end-to-end audiobook synthesis: từ text normalization đa ngôn ngữ, pipeline xử lý lỗi/chấm điểm bằng Whisper QC loop, đến cơ chế journal phục hồi khi crash cho audiobooks dài hơn 10 tiếng.
