Key idea

phonon-31m-en là mô hình Text-to-Speech (TTS) kích thước cực nhỏ (31M tham số) dành riêng cho tiếng Anh, có khả năng streaming on-device trên trình duyệt, điện thoại hoặc CPU máy tính. Mô hình kết hợp flow-matching transformer với Mimi codec (Kyutai), cho phép xuất âm thanh 24 kHz với độ trễ mỗi khung hình 80 ms dưới giấy phép thương mại Apache 2.0.

Problem

Nhiều mô hình TTS chất lượng cao hiện nay có kích thước tham số lớn, đòi hỏi GPU mạnh mẽ hoặc phụ thuộc vào cloud API với độ trễ khứ hồi cao (round trip latency), không phù hợp cho các tác vụ tương tác thời gian thực, trợ lý giọng nói ngoại tuyến (offline) hoặc các thiết bị biên (edge devices) bị giới hạn tài nguyên.

Methodology

Phonon được phát triển dựa trên Pocket TTS và audio codec Mimi từ Kyutai. Kiến trúc gồm một flow-matching transformer dự đoán các audio latent từ văn bản đầu vào theo từng khung hình 80 ms (frame-by-frame), sau đó Mimi decoder chuyển đổi latent thành dạng sóng âm thanh mono 24 kHz. Mô hình hỗ trợ streaming ngay trong quá trình sinh latent. Trọng số được lượng tử hóa 8-bit (q8) định dạng GGUF với kích thước chỉ 64.5 MB. Mô hình hỗ trợ voice cloning/prompting thông qua embedding âm thanh đầu vào (ví dụ định dạng .safetensors với shape (num_frames, 512)).

Setup

Mô hình hỗ trợ tiếng Anh (mono, 24 kHz). Hệ sinh thái runtime đa nền tảng gồm: thư viện Python ptts (qua PyPI hoặc uvx), Hugging Face transformers (GradiumPhononTTSForConditionalGeneration), Web/WASM (phonon-tts npm), iOS/macOS (Core ML / Swift), Android (bao gồm hỗ trợ Snapdragon NPU), Docker API tương thích OpenAI, WebSocket server, Rust (ptts crates.io) và C/C++ FFI. Đánh giá thực nghiệm so sánh với Kokoro, Magpie và NeuTTS thông qua: Elo (human preference mù từ 468 người chấm, 8.290 lượt bình chọn), Hard set LLM WER (đoạn văn phức tạp chứa số, ngày tháng, mã, đơn vị đo) và Seed-TTS LLM WER.

Results

  • Elo rating (English US, 468 raters, 8.290 votes): phonon-31m-en đạt 2098 điểm (vượt Kokoro 2043, NeuTTS 2034, Magpie 1939; xếp sau phonon-40m-en đạt 2117).
  • Hard set LLM WER (English US): phonon-31m-en đạt 1.5% (tốt nhất bảng, vượt phonon-40m-en 2.3%, phonon-40m-multilingual 2.0%, Kokoro 3.5%, NeuTTS 8.7%, Magpie 28%).
  • Seed-TTS LLM WER (English US): phonon-31m-en đạt 0.51% (so với Kokoro 0.45%, phonon-40m-en 0.45%, phonon-40m-multilingual 0.48%, Magpie 0.46%, NeuTTS 0.62%).

Limitations

Mô hình chỉ hỗ trợ tiếng Anh; văn bản ngôn ngữ khác sẽ bị phát âm sai. Cần module chuẩn hóa văn bản (text normalization) phù hợp để đọc đúng số, ngày tháng và ký hiệu. Văn bản dài bị chia nhỏ theo câu nên ngữ điệu (prosody) không duy trì liền mạch xuyên suốt toàn bộ đoạn văn. Tài liệu không công bố chi tiết về tập dữ liệu huấn luyện hoặc thời lượng giờ âm thanh đã dùng.

Takeaways

Lựa chọn hàng đầu cho các kỹ sư cần triển khai TTS streaming siêu nhẹ trên edge/on-device (WASM, mobile, CPU) với chất lượng tiếng Anh cao, license thương mại Apache 2.0 và hệ sinh thái đa ngôn ngữ lập trình hoàn chỉnh.
