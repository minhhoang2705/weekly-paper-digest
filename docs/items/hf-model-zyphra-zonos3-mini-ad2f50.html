Inference runtime for ZONOS3-Mini, Zyphra's multilingual text-to-speech model: HTTP servers that serve the Zonos Voice Studio, an in-browser WebGPU build and an offline Python API. Model details are in About ZONOS3-Mini. Blog post · Weights · Run in your browser (no install) · Zyphra Cloud · ZTTS2-Eval Quick start. 1. Choose a backend. | Machine | Backend | Setup | | Linux x86_64 with an NVIDIA GPU (tested on H100) | CUDA server on Mini-SGLang (servers/sgl) | below | | Apple Silicon Mac | MLX server (servers/mlx) | below; details in servers/mlx/README.md | | CPU, CUDA, Metal or Vulkan, no Python at runtime | C++/ggml server and CLI (servers/ggml) | servers/ggml/README.md | | A browser with WebGPU, no server | In-browser server (servers/web, the studio's ?api=web) | nothing to install: run it in your browser; to build it, servers/web/README.md | Every server implements the same HTTP API and serves the same studio. 2. Prerequisites. - uv; the project pins Python 3.12. - ggml server: a Rust toolchain (rustup, stable). Key idea

ZONOS3-Mini là mô hình Text-to-Speech (TTS) mã nguồn mở của Zyphra với tổng cộng 800M tham số nhưng chỉ có khoảng 100M active parameters cho mỗi token nhờ kiến trúc MoE thưa. Mô hình hỗ trợ 43 ngôn ngữ, cho phép voice cloning độ trễ cực thấp và có khả năng chạy thời gian thực trên điện thoại, máy tính cá nhân hoặc trực tiếp trên trình duyệt qua WebGPU.

Problem

Các mô hình TTS chất lượng cao kèm tính năng voice cloning đa ngôn ngữ thường có kích thước lớn, đòi hỏi tài nguyên tính toán cao và độ trễ sinh âm thanh lớn, gây khó khăn cho việc triển khai trên thiết bị cục bộ (edge/on-device) hoặc trong các ứng dụng thời gian thực như trợ lý ảo và game.

Methodology

Mô hình gồm 11 layer (chiều ẩn 1.024) với cấu trúc lai gdn3_global1: 9 lớp Gated DeltaNet (GDN) kết hợp 2 lớp global attention (16 heads \times 32 dims, 4 KV heads) và residual attention toàn phần, hỗ trợ ngữ cảnh 32.768 vị trí. Sử dụng cơ chế latent MoE với 64 chuyên gia (top-2 routing từ layer 1), giữ khoảng 100M tham số kích hoạt per token. Văn bản được mã hóa bằng SuperBPE (8.192 token) kèm chuẩn hóa NeMo (cho 9 ngôn ngữ). Mô hình sinh tự hồi quy chuỗi token âm thanh ở tần số 15 Hz với dual-codec ZAC 1 gồm 10 codebooks (1 codebook ngữ nghĩa chưng cất từ Wav2Vec2-BERT và 9 codebooks âm học, mỗi codebook 4.096 mục). Điều kiện hóa bằng đoạn audio tham chiếu (tối đa 60 giây, áp dụng speaker CFG) hoặc 1 embedding MECT-B2 192 chiều, cùng 3 nhóm điều khiển âm học (độ to LUFS 10 bucket, băng thông f_{\max} 10 bucket, tốc độ nói theo byte/giây 30 bucket). Đầu ra được giải mã về âm thanh 44.1 kHz qua đầu causal multi-resolution iSTFT (full_mr hoặc bản tỉa gọn keep2_plain).

Setup

Hỗ trợ 43 ngôn ngữ thuộc nhiều khu vực (Tây/Bắc/Đông Âu, Trung Đông, Đông Á, Đông Nam Á, Nam Á). Mô hình định dạng bf16, các đầu giải mã chạy fp32. Đánh giá chất lượng và tốc độ thực hiện trên 1 GPU NVIDIA H100 80GB qua benchmark ZTTS2-Eval v2 (gồm 35 tập FLEURS-R và 20 tập VoxBlink2, tổng 55 tập con đa ngôn ngữ). Các runtime triển khai gồm WebGPU, C++/ggml, MLX, CUDA và server SGLang-Omni qua chuẩn API /v1/audio/speech.

Results

  • Độ trễ đến đoạn âm thanh đầu tiên (median time to first audio): đạt 80 ms với 8 request đồng thời trên 1 GPU NVIDIA H100 80GB (sử dụng speaker-embedding prompt).
  • Thông lượng tối đa (peak throughput): đạt 457 giây âm thanh trên mỗi giây tính toán thực tế tại mức concurrency tối ưu trên 1 GPU NVIDIA H100 80GB.
  • Hỗ trợ độ dài ngữ cảnh sinh âm thanh liên tục lên đến 10 phút cho mỗi lượt tạo với codec 15 Hz (hop size 2.940 mẫu ở 44.1 kHz).

Limitations

Tài liệu mô tả mô hình không cung cấp bảng chi tiết điểm số WER, MOS hoặc Speaker Similarity tuyệt đối (chỉ trích dẫn chỉ số tổng hợp 1/2 z(\text{similarity}) - 1/2 z(\text{WER}) và điều hướng về bài blog ngoài). Bộ chuẩn hóa văn bản NeMo chỉ hỗ trợ 9 ngôn ngữ; 34 ngôn ngữ còn lại phải truyền văn bản dạng thô nguyên bản.

Takeaways

Sự kết hợp giữa cơ chế trộn tuần tự Gated DeltaNet với Sparse MoE và codec tần số thấp (15 Hz) đi kèm causal iSTFT là giải pháp tối ưu giúp đưa mô hình TTS 44.1 kHz đa ngôn ngữ chất lượng cao về ngưỡng 100M active params, đủ nhẹ để chạy mượt mà ngay trên trình duyệt bằng WebGPU mà vẫn đạt TTFA 80 ms trên server.
