Key idea

Boubou là một runtime và CLI mã nguồn mở viết bằng Rust, cho phép chạy voice agent AI hoàn toàn cục bộ trên máy cá nhân mà không cần tài khoản hay API đám mây. Dự án hỗ trợ cả mô hình âm thanh tích hợp (Liquid models qua llama.cpp) lẫn kiến trúc pipeline mô-đun (ASR + LLM + TTS như Qwen3-TTS), kèm khả năng voice cloning và máy chủ tương thích OpenAI Realtime API.

Problem

Các trợ lý giọng nói AI (voice agents) tiên tiến hiện nay chủ yếu phụ thuộc vào API điện toán đám mây đắt đỏ, gây rủi ro về quyền riêng tư âm thanh/dữ liệu và yêu cầu kết nối mạng liên tục, trong khi việc tự thiết lập pipeline cục bộ (ASR, LLM, TTS, echo cancellation, voice cloning, serving) thường phức tạp đối với người dùng cuối và lập trình viên.

Methodology

Boubou được xây dựng trên tầng nền tảng Rust kết nối micro và loa với server mô hình cục bộ, tích hợp sẵn khử tiếng vọng (echo cancellation) và phát hiện giọng nói (speech detection). Dự án cung cấp 2 chế độ xử lý: (1) Mô hình đơn nguyên (One audio model) với Liquid models (ví dụ LFM3-Omni-2B) xử lý trực tiếp nghe, tư duy và nói thông qua llama.cpp; (2) Pipeline mô-đun gồm speech recognition -> Qwen -> TTS (ví dụ qwen3-tts:0.6b-customvoice). Ngoài ra, công cụ hỗ trợ lệnh clone (sử dụng Whisper để phiên âm đoạn âm thanh mẫu và Qwen3-TTS Base weights để trích xuất/sao chép giọng) và lệnh serve cung cấp giao diện web qua QR code/LAN HTTPS (chứng chỉ từ lan.runboubou.com hoặc --self-signed), đồng thời mở các endpoint tương thích OpenAI Realtime và speech API (GET /v1/audio/voices).

Setup

Yêu cầu hệ thống: Apple Silicon Mac chạy macOS 13.3+ với Node.js 18+, hoặc Linux (x86-64, arm64 với glibc 2.38+, OpenSSL 3, libgomp, C compiler, pkg-config, ALSA headers). Biên dịch từ nguồn bằng Rust 1.91+ (cargo build --locked --release). Thao tác triển khai qua launcher npm npx boubou@beta, hỗ trợ cờ --offline, cấu hình thư mục lưu trữ qua biến môi trường BOUBOU_HOME (mặc định ~/Library/Caches/boubou trên macOS hoặc ~/.cache/boubou trên Linux).

Results

  • Không có số liệu định lượng (như WER, MOS, latency/RTF, FPS) được nêu trong tài liệu.

Limitations

Tài liệu không công bố bất kỳ số liệu đo đạc hiệu năng nào (độ trễ phản hồi, mức tiêu thụ tài nguyên RAM/VRAM, hay chất lượng giọng nói). Hỗ trợ GPU NVIDIA trên Linux chỉ được đề cập hướng dẫn qua web mà không có chi tiết cụ thể trong README. Chế độ serve chỉ cho phép một client tương tác đàm thoại tại một thời điểm.

Takeaways

Boubou là một giải pháp đóng gói all-in-one tiện lợi cho các kỹ sư muốn nhanh chóng dựng voice agent chạy offline/on-device (đặc biệt tối ưu cho Apple Silicon Mac) và cung cấp API chuẩn OpenAI Realtime để tích hợp vào ứng dụng hoặc robot mà không phải cấu hình thủ công chuỗi ASR-LLM-TTS.
