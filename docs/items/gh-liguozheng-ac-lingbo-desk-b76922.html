Key idea

Lingbo Desk (聆泊) là một nguyên mẫu voice agent trên hệ điều hành Windows kết hợp giao tiếp giọng nói liên tục, nhân vật Live2D và tiến trình thực thi tác vụ nền độc lập. Dự án nhắm vào công việc xử lý tài liệu cá nhân với khả năng tạm dừng điều chỉnh yêu cầu (human-in-the-loop) và kiểm chứng bàn giao bằng bằng chứng thực thi (hash SHA256, biên nhận).

Problem

Các desktop agent thường gặp rủi ro thao tác sai khi tự ý chỉnh sửa tệp tin, mô hình LLM báo 'hoàn thành' nhưng tệp không tồn tại hoặc sai yêu cầu, người dùng không thể can thiệp/điều chỉnh khi tác vụ dài đang chạy, hoặc toàn bộ giao tiếp bị khóa trong lúc agent đang gọi công cụ.

Methodology

Kiến trúc tách rời giao tiếp và thực thi: (1) Giao diện Electron/Vue đảm nhiệm nhân vật Live2D (chớp mắt, nhép miệng theo cường độ âm thanh), thu âm/phát âm thanh và bàn làm việc (workbench); (2) Gateway Node.js phụ trách quản lý phiên, định tuyến mô hình (DeepSeek cloud API hoặc Ollama cục bộ), adapter thoại (ASR/TTS tiếng Trung, Nhật, Anh qua cắt lát âm thanh thay vì mô hình end-to-end), và chính sách bảo mật; (3) Tiến trình làm việc Agent riêng biệt (worker process) chạy vòng lặp tool calling tương tác qua IPC/HTTP nội bộ; (4) Quản lý tác vụ cho phép tạm dừng (pause), lưu phiên bản yêu cầu mới và kiểm tra trạng thái trước khi khôi phục; (5) Hệ thống kiểm soát tệp kiểm tra quyền thư mục, SHA256 tệp gốc, tạo bản sao lưu, xem trước thao tác trước khi người dùng xác nhận, và nghiệm thu qua work_finish cùng kiểm tra hash sản phẩm bàn giao.

Setup

Môi trường yêu cầu: Windows x64, Node.js 24, pnpm 11, Python 3.12. Cần cấu hình biến môi trường .env với API key DeepSeek hoặc endpoint Ollama, dịch vụ ASR/TTS riêng biệt, và nạp thư viện live2dcubismcore.min.js (không đi kèm repo). Cổng mặc định của backend và workspace là http://127.0.0.1:3850.

Results

  • Vượt qua 142 bài kiểm tra tự động hóa backend và 3 bài test giám sát chẩn đoán.
  • Vượt qua 11 điểm kiểm tra (checkpoints) liên kết văn bản với mô hình thực tế (hội thoại đa lượt, điều khiển tác vụ, bàn giao tệp, hủy và khôi phục trạng thái sau khi khởi động lại).
  • Đạt 69 bài test mô phỏng runtime hội thoại và 7 bài test mô phỏng logic ngắt lời (barge-in).
  • Bản ghi mẫu thực tế dài khoảng 153 giây thực hiện đối chiếu báo giá Trung - Nhật, tạm dừng đổi yêu cầu và xuất báo cáo Word kèm tệp Markdown.

Limitations

Xử lý thoại là dạng cắt lát âm thanh rồi đưa qua ASR thay vì mô hình audio-to-audio end-to-end. Chưa có sandbox cấp hệ điều hành (script Skills chạy với quyền người dùng hiện tại). Bộ nhớ dài hạn chưa hỗ trợ tự động đúc kết hay vector retrieval. Các lỗi như lag focus khung chat, cửa sổ trắng và thoát ứng dụng chưa xác định rõ nguyên nhân; từng có trường hợp mô hình thông báo hoàn thành lệch với trạng thái thực tế của backend.

Takeaways

Cung cấp một kiến trúc mẫu chuẩn chỉnh cho desktop voice agent có tính an toàn cao: tách riêng tiến trình hội thoại và worker chạy tool, dùng state machine có phiên bản yêu cầu, và bắt buộc đối soát SHA256 trước khi sửa tệp thay vì tin tưởng mù quáng vào output của LLM.
