Official Fish Audio plugin for Hermes Agent: expressive text-to-speech, speech-to-text, voice library, cloning and voice design. README: Fish Audio for Hermes. The official Fish Audio plugin for Hermes Agent, maintained by Electric Sheep. Give your agent a voice: expressive speech in 80+ languages, Fish Audio's library of community voices, your own cloned or designed voices, and accurate speech-to-text. It works in the Hermes CLI, every messaging app Hermes supports and the Desktop app. This installs the reviewed release pinned in the Hermes plugin catalog. To follow the repository's latest main instead: On Hermes 0.21.6 and newer, Hermes asks before installing the plugin's Python dependencies; in a script, add --yes-deps. Hermes 0.21.5 installs them without asking and has no --yes-deps flag. On either version, hermes plugins enable fish-audio afterwards also installs them. hermes fish login checks the key against your Fish account and saves it to the active profile. It makes Fish Audio the speech and transcription provider where none is set, and replaces another provider only if you confirm at the prompt or pass --yes. Once Fish Audio is the provider, voice replies, read-aloud and voice notes go through it. Key idea

Đây là plugin chính thức tích hợp Fish Audio vào Hermes Agent (NousResearch), cung cấp giải pháp thoại toàn diện gồm TTS biểu cảm với hơn 80 ngôn ngữ, voice cloning/design và STT trực tiếp. Hệ thống hỗ trợ streaming độ trễ thấp và tích hợp sâu từ giao diện dòng lệnh (CLI/TUI) đến Hermes Desktop.

Problem

Hermes Agent cần một hệ thống xử lý giọng nói hoàn chỉnh, độ trễ thấp cho cả chiều nghe và nói, hỗ trợ streaming trực tiếp theo thời gian thực và quản lý giọng nói linh hoạt (thư viện cộng đồng, sao chép giọng nói) trên cả CLI lẫn giao diện đồ họa Desktop.

Methodology

Plugin hoạt động như provider TTS và STT cho Hermes Agent thông qua API của Fish Audio (api.fish.audio):

  • TTS Streaming: Sử dụng các model Fish Audio S2 (s2.1-pro, s2-pro, s1) và Drama 3 (drama-3). Với Hermes 0.21.6+, plugin stream dữ liệu âm thanh 24 kHz PCM từ endpoint POST /v1/tts theo từng câu đến CLI, TUI và Desktop read-aloud.
  • Live Dictation (STT): Kết nối qua WebSocket realtime tương thích ElevenLabs (wss://api.fish.audio/compat/elevenlabs/v1/speech-to-text/realtime). Hệ thống chỉ commit phrase khi phát hiện tối thiểu 300 ms âm thanh vượt ngưỡng voice.silence_threshold (100 ms đối với từ cuối), và tự động fallback sang cơ chế transcription file nếu phiên streaming đứt đoạn.
  • Model Tools & Plugin Skills: Cung cấp bộ công cụ gọi hàm cho agent gồm fish_speak (tổng hợp đa giọng đọc kèm word timings, phụ đề SRT/WebVTT), fish_voices (tìm kiếm, tạo giọng qua prompt mô tả hoặc clone từ 1–3 file mẫu \le 10 MB), và fish_transcribe (nhận diện kèm diarization và mốc thời gian).
  • Kiến trúc Desktop: Tách làm hai phần đóng gói chung: routes trên agent gateway và giao diện Voices page nhúng trong Hermes Desktop hỗ trợ 9 ngôn ngữ hiển thị.

Setup

Yêu cầu Hermes Agent 0.21.5 trở lên (yêu cầu 0.21.6+ cho streaming và live dictation), Python 3.11+, hệ điều hành macOS hoặc Linux (Windows chưa kiểm thử). Cài đặt qua lệnh hermes plugins install fish-audio --enable và thiết lập API key với hermes fish login. Hỗ trợ 80+ ngôn ngữ tổng hợp giọng nói và 9 ngôn ngữ giao diện Desktop (en, zh, zh-hant, ja, ar, ru, fr, de, es).

Results

  • Đo lường thời gian nhận byte âm thanh đầu tiên (HTTP streaming time to first audio, N=3, p50 thực hiện từ Tokyo trên v1.3.2): 0.293 s trên s2.1-pro, 0.266 s trên s2-pro và 0.244 s trên s1.
  • Độ trễ nhận byte âm thanh đầu tiên tổng thể: Fish HTTP API p50 đạt 243 ms (khoảng 238–356 ms qua 3 mẫu), CLI voice mode đạt 373–381 ms, Desktop speak-stream handler (in-process) đạt 310 ms.
  • Thời gian tổng hợp nguyên file MP3 độ dài 310 ký tự: mất 3.605 s trên s2.1-pro và 2.209 s trên s2-pro.
  • Độ chính xác STT của transcribe-1-pro trên synthetic speech corpus sạch: Word Error Rate (WER) tiếng Anh đạt 1.8%, Character Error Rate (CER) tiếng Nhật và tiếng Trung đạt 0.

Limitations

Live dictation chỉ hiển thị theo từng phrase đã commit chứ không xuất hiện interim text từng từ; live dictation không khả dụng với remote self-hosted base_url hoặc dưới chế độ cô lập host plugin (plugins.isolation: host). Text normaliser của Hermes core làm biến dạng thẻ markup <|speaker:N|> và thẻ Drama 3 trên luồng text_to_speech mặc định nên buộc phải dùng tool fish_speak. Nền tảng Windows chưa được kiểm thử.

Takeaways

Dự án là một mẫu tích hợp chuẩn chỉnh cho kỹ sư muốn đưa mô hình speech-to-speech/voice agent từ dịch vụ cloud vào kiến trúc agent mã nguồn mở, kết hợp khéo léo giữa streaming VAD, cơ chế phê duyệt an toàn (approval gate) và giao diện người dùng desktop.
